# 2026-03-23 工作日志

## 选股模型深度分析

对 BBBIG 选股系统做了全面分析，主要发现：

### 架构
- 三级漏斗：量化预筛(5000→200) → 多因子评分(→TOP80) → DeepSeek AI(→TOP10) → 回测验证重排
- 风控体系：大盘熔断 + 仓位动态调节 + 全局止损熔断 + 冷静期机制

### 核心问题
1. **候选池大票偏见**：成交额TOP140天然偏向大盘蓝筹，小盘成长股入选难
2. **AI信息冗余**：AI在量化已覆盖的维度上重复打分，缺乏信息增量
3. **回测未来信息泄漏**：历史选股用当日数据而非历史时点数据
4. **多因子权重手工调参**：未经数据验证优化
5. **板块资金流数据薄弱**：concept表为空，降级为涨跌幅代理
6. **缺少消息面/基本面深度**：纯技术面+AI通用分析

### 改进优先级
- P0: 候选池分层抽样、AI角色重定义
- P1: 财务指标深度分析、多因子权重优化、消息面策略
- P2: 板块数据源补充、回测修复、硬止损线

## P1: 消息面情绪分析（FinGPT 风格）

### 新增文件
- **sentiment_analyzer.py**: 情绪分析核心模块
  - `SentimentAnalyzer` 类：调用 DeepSeek 做批量行业/个股情绪打分（-1~+1）
  - FinGPT 风格 prompt：金融情绪分析专家角色，输出结构化 JSON
  - `filter_by_sentiment()`: 综合情绪=行业*0.4+个股*0.6，低于阈值的标的直接过滤
  - `aggregate_news_by_industry/stock()`: 新闻按行业/个股聚合工具函数
  - 行业关键词提取降级匹配（半导体/新能源/医药等30+行业映射）

### 修改文件
- **config.py**: 新增5个情绪分析配置项
  - `SENTIMENT_ENABLED=True` 开关
  - `SENTIMENT_NEGATIVE_THRESHOLD=-0.3` 利空过滤阈值
  - `SENTIMENT_NEWS_DAYS=3` 新闻回溯天数
- **db_cache.py**: 新增2张表 + 10个方法
  - `news_cache` 表：新闻缓存（按日期+代码索引）
  - `sentiment_cache` 表：情绪结果缓存（避免重复调用 AI）
  - save/get/has_news, save/get/has_sentiment 等完整 CRUD
- **data_fetcher.py**: 新增2个接口
  - `fetch_news()`: 获取近N日新闻快讯（Tushare news + major_news），SQLite 缓存优先
  - `fetch_stock_news()`: 按股票名称关键词匹配个股相关新闻
- **stock_selector.py**: 选股流程从6步扩展为7步
  - 新增 Step [5/7] 消息面情绪过滤
  - 获取新闻 → 按行业/个股聚合 → DeepSeek 情绪打分 → 利空标的过滤
  - 情绪缓存优先，避免重复分析
  - AI prompt 中新增消息面情绪概览，告知 AI 哪些行业利空/利好
  - 报告输出新增【消息面情绪分析】板块 + 过滤日志
